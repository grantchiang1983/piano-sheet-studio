# 🎹 Piano Sheet Studio - 音樂鋼琴五線譜互動系統

一個現代化、免安裝依賴、具備豐富互動體驗的**鋼琴五線譜學習與演奏系統**。

---

## ✨ 核心特色

- **🎼 高精度大譜表五線譜 (Grand Staff)**：
  - 標準雙行大譜表（高音譜表 Treble Clef + 低音譜表 Bass Clef）。
  - 自動計算上加線/下加線（Ledger Lines）與升降記號（♯ / ♭）。
  - 即時彈奏反饋：按下任何鍵，五線譜即刻呈現對應音符、音名、唱名 (Do Re Mi) 與簡譜。
- **🧠 即時和弦辨識儀 (Real-time Chord Analyzer)**：
  - 同時按下多個音符時，自動分析調性與和弦結構（如 C Major 大三和弦、Am7 小七和弦、G7 屬七和弦等）。
- **🎹 擬真 3D 虛擬鋼琴**：
  - 象牙白鍵與黑檀木黑鍵質感，支援 37 / 49 / 61 / 88 鍵切換。
  - 琴鍵標籤自由切換（音名、唱名、簡譜數字、電腦鍵盤按鍵或純淨模式）。
  - 支援滑鼠點擊、滑奏 (Glissando)、多點觸控 (Touch)。
- **💻 電腦打字鍵盤演奏 (QWERTY)**：
  - 支援用日常電腦鍵盤彈奏超過兩組完整八度音域。
  - 按住 **空白鍵 (Spacebar)** 即時觸發延音踏板 (Sustain Pedal)！
- **🎵 經典名曲示範與跟彈練習**：
  - 內建《小星星變奏曲》、《給愛麗絲》、《歡樂頌》、《卡農》、《巴哈小步舞曲》。
  - **自動示範播放**：樂譜音符與琴鍵雙向高亮跑動，支援 BPM 節拍器與速度調整 (0.75x ~ 1.25x)。
  - **跟彈練習模式 (Wait-for-you)**：樂譜游標等待您彈下正確音符後才前進，具備連擊 (Streak) 與準確度統計。
- **🔌 外接實體 USB MIDI 鍵盤支援 (Web MIDI API)**：
  - 將電子琴、電鋼琴以 USB 連接電腦，瀏覽器自動偵測，隨插即彈，延音踏板同步支援。
- **🎙️ 自創曲旋律錄音轉譜**：
  - 點擊「● 錄製彈奏」彈出旋律，結束後自動轉化為專屬五線譜並可重播。
- **⚡ 零依賴開箱即用**：
  - 純 HTML5 + CSS3 + Web Audio API 物理泛音合成，不需要安裝 Node.js 或 Python，點擊即可運行。

## 🚀 快速啟動

### 方法一（推薦：Windows 一鍵啟動）
直接雙擊專案資料夾內的：
```
start_app.bat
```

### 方法二（直接以瀏覽器開啟）
在任何現代網頁瀏覽器（如 Google Chrome、Microsoft Edge、Firefox 等）中直接開啟：
```
index.html
```

## 🎶 五線譜識譜小教室

- **大譜表 (Grand Staff)**：由上方的高音譜表與下方的低音譜表結合而成，中間由中央 C (C4) 相連。
- **高音譜表 (Treble Clef 𝄞)**：主要記錄中高音域（一般為右手演奏），下加一線即為 **中央 C (C4)**。
- **低音譜表 (Bass Clef 𝄢)**：主要記錄中低音域（一般為左手演奏），上加一線亦為 **中央 C (C4)**。
- **升降記號 (Accidentals)**：
  - `♯` (升記號 Sharp)：音高向上升高半音（對應鍵盤右側相鄰黑鍵）。
  - `♭` (降記號 Flat)：音高向下降低半音（對應鍵盤左側相鄰黑鍵）。
